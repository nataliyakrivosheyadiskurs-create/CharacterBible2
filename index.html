Импорт данных

Загрузи JSON из старого приложения — персонажи, связи и изображения импортируются автоматически. CSV-файл позволяет импортировать базовую информацию о персонажах.

1 Экспортируй из старого приложения Используй кнопку JSON-экспорта — он сохраняет всё: поля, роли, связи и ссылки на изображения.
2 Загрузи и проверь После выбора файла увидишь предварительный список — до записи в базу.
3 Подтверди импорт Данные запишутся в новый Supabase. Операция необратима, но не затрагивает старое приложение.
💡 Рекомендуемый формат — JSON

JSON из старого приложения содержит полную структуру: связи с двух сторон, роли по книгам, ссылки на изображения в Supabase Storage.

CSV подходит для базовой информации о персонажах без связей и фото.
